# Low-level substitute disclosure — Stage A draft

> Status: configuration and static scope are verified; numeric substitute-use and symmetry claims remain pending frozen-snapshot runtime evidence. This text is not submission-ready until Tables A, B, and D are populated from formal episodes.

For Option B experiments, we disable both planner-layer task-specialization paths by setting `DC3PA_LEGACY_TASK_HACKS=0`: `Planner._inject_prerequisite_steps` and `Evaluator._fixed_workflow_for_task`. This prevents a hand-authored prerequisite sequence and the fixed redstone workflow from being credited to the proposed planning mechanism. We retain `DC3PA_CONTROLLER_BOUNDED_RESOURCE_FALLBACK=1` solely as a disclosed low-level execution substitute for the unavailable MP5 interface. Its active gate is limited to controller runtime targets `diamond`, `redstone`, and `gold`; on the frozen 50-task catalog, static target matching predicts two potentially touched tasks—`obtain diamond` and `mine redstone` (2/50, 4%, both complex)—pending runtime registry validation.

The substitute can run only after the controller finds missing material/tool conditions around deep-mining and bounded UI/resource attempts. It writes whole-inventory states through the controller's `_set_inventory_from_memory`; observed positive deltas will be reported per task and item from the Stage A inventory-write log. The recorder is attached externally and forwards the original `set_inventory` arguments and return value unchanged. Its action-sequence/terminal-outcome A/B comparison and each mode's actual call rate are pending. Consequently, no claim that the substitute is empirically symmetric across `mp5_legacy`, `reasoning_only`, and `dc3pa` is made here; Table B will determine whether the required ≤10% calls-per-episode criterion holds.

Numbers attributed to MP5 or Optimus-1 in their original papers did not use this substitute and are reference values only; they are not causal evidence for the present implementation. Every key comparison will report both the full 50-task population and the substitute-free subset. If Table B is asymmetric, comparisons on touched tasks will be explicitly treated as confounded and Stage D claims will be restricted to the untouched subset.
