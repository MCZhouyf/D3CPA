# DC3PA Round 5.11: V5 Development and Independent Calibration

Round 5.11 collects `dev_train` and `dev_tune` evidence against the canonical
pressure-plate taskset and read-only MineCLIP[attn] Paper Memory V5. The existing
single-chain Planner, Reflection, Controller, Evaluator, and formal Log Bootstrap
remain the behavior policy.

Knowledge V2, ordinal Confidence, and Environment V2 are passive observers. Their
outputs cannot select, reject, or revise actions. Every immutable decision record
binds the source commit, development protocol, input release, V5 snapshot root,
task/seed, bootstrap policy, provider usage, and existing correctness join.

## Protected Data Boundary

The three-way protocol is audited before collection. The full assignment set is
used only by the offline protocol compiler. Afterwards, `dev_holdout` plaintext is
sealed outside the repository and is not mounted in Stage 6. The campaign runner
accepts only a train/tune manifest and rejects holdout or superseded `mine sand`
assignments.

## Frozen Analysis

Confidence uses five ordinal levels, symmetric Laplace smoothing with alpha 1,
and weighted PAV. Environment uses action-conditioned top-3 V5 scenes and a
pre-outcome one-factor-at-a-time candidate grid when no prior compatible grid
exists. Train fits component probabilities; tune reports or selects. Fusion
features are exported in the frozen order `knowledge_coverage`,
`knowledge_unknown`, `confidence_probability`, `environment_probability`.

## Scope

This round does not fit Fusion, access holdout, run final evaluation, implement
Trigger, modify Paper Memory V5, or start Round 6. Real artifacts, assignments,
receipts, traces, model identities, and releases remain outside Git.
