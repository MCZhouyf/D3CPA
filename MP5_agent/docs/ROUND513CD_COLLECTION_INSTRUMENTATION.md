# Round 5.13C-D prospective collection and instrumentation

Round 5.13C defines a new prospective Track E collection protocol. Historical
development rows remain baseline-only and are not eligible for V4.1 fitting.
No formal seed or assignment is generated by the contract builder.

Track E executes exactly one Planner-proposed action with five-level confidence
from the same generation. Evaluation is disabled before that action, Paper
Memory V5 is read-only, and the post-execution label is joined from structured
state evidence. Track C is only a separate replay-feasibility blueprint; no CDT
parameter is defined or estimated.

The public repository contains code, tests, and DRAFT schemas only. Immutable
contracts and any later decision rows belong in an external artifact root.
Engineering smoke execution requires a separate author-approved design and run
binding. Until that approval exists, readiness must be reported as `BLOCKED`.

## Review record

Scientific observability review found that the historical confidence provider
was a separate model call and could not satisfy same-generation confidence.
The old development collector was therefore not reused. Immutability review
also required a dedicated mode, fail-closed observer, deterministic record IDs,
atomic pre/post materialization, and explicit exclusion of engineering data.

The repository does not specify approved numeric bilateral thresholds for this
new engineering smoke. They must be supplied by an approved external run
binding; this implementation does not invent them.
